# AI Agent Cybersecurity

Learner lab repository for the WSQ course **AI Agent Cybersecurity**
Course code: **TGS-2025053228**

The ten progressive labs show how to secure AI agents such as OpenClaw and Hermes across policy design, prompt-injection defence, least-privilege tools, secrets, monitoring, network evidence, incident response and human-governed continuous improvement.

## Labs

Each lab has its own folder and contains:

- a detailed step-by-step `README.md`;
- `AI-PROMPTS.md` and a printable `AI-PROMPTS.pdf`;
- runnable Python scripts using the standard library;
- synthetic mock data and an evidence folder;
- a deterministic `python3 verify.py` acceptance check.

Open the [complete lab index](labs/README.md) for the learning-outcome map, tool links, safety rules and all ten labs.

## Quick start

```bash
git clone https://github.com/tertiarycourses/TGS-2025053228-AI-Agent-Cybersecurity.git
cd TGS-2025053228-AI-Agent-Cybersecurity/labs/lab-01-agent-security-policy-trust-boundaries
python3 verify.py
```

No external Python package is required. Use only synthetic data and the explicitly authorised training targets named in the lab instructions.
